## 🛡️ First Run / 首次运行

The app is **not code-signed** — a security warning on first launch is normal, not a virus. Choose **"Run Anyway / Open Anyway"** once, then you're all set.

应用**未做代码签名**，首次启动的系统拦截属正常保护，**不是病毒**——选**"仍要运行 / 仍要打开"**一次即可。

| Platform / 平台 | What to do / 操作 |
|---|---|
| macOS | Right-click → Open → **Open** / 右键 → 打开 → **仍要打开** |
| Windows | **More info → Run anyway** / **更多信息 → 仍要运行** |
| Linux | `chmod +x AllDownloader` then run / 赋执行权限后运行 |

> Windows: no prompts after installation / Windows 安装完成后不再提示
