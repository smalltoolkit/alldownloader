## 🛡️ First Run: "Open Anyway / Run Anyway" / 首次运行："仍要打开 / 仍要运行"说明

The app is **not code-signed** (Apple Developer / Windows code-signing certificates require a paid subscription), so your system may show a security warning on first launch. This is normal protection for "unidentified apps" — **not a virus or corruption**. Choose "Run Anyway / Open Anyway" once and you're all set.

应用**未做代码签名**（Apple Developer 证书 / Windows 代码签名证书均需付费申请），因此首次运行时系统会弹出安全拦截提示。这是系统对"来源不明应用"的正常保护，**不是病毒或损坏**——选择"仍要运行/打开"一次即可，之后正常使用。

| Platform / 平台 | What you see / 现象 | What to do / 操作 |
|---|---|---|
| macOS | "cannot be opened because the developer cannot be verified" / 提示"无法打开，因为它来自身份不明的开发者" | Right-click the app → Open → click "Open" again; no more prompts afterwards / 右键点击应用 → 打开 → 再次点击"打开"；此后不再提示 |
| Windows | SmartScreen "Windows protected your PC" when running Setup.exe / 运行 Setup.exe 时 SmartScreen 弹"已阻止" | Click "More info" → "Run anyway"; no more prompts after installation / 点"更多信息"→"仍要运行"；安装完成后启动 exe 不再提示 |
| Linux | "Permission denied" after extracting / 解压后提示权限不足 | `chmod +x AllDownloader` then run / 赋执行权限后运行 |

> After installing via the Windows Setup.exe, files are written **without** the "from the internet" mark, so day-to-day launches won't trigger the warning — only the first install may show it once.
> 说明：Windows 安装包安装后写出的文件**不带"来自互联网"标记**，所以安装完成后日常启动**不会**再触发拦截，只有首次安装时可能提示一次。
